# AI全栈开发实习：项目经历与证据

## 可直接使用的项目描述

**电商售后自动化平台｜AI全栈开发**

技术栈：React · TypeScript · Vite · Python · FastAPI · MySQL · LangGraph · MCP · Docker Compose

- 在既有单Agent项目上扩展React客户与审批员工作台，接入登录、订单/物流、AI对话、售后申请、审核理由、处理进度、审计和异常恢复，完成浏览器到真实MySQL的沙箱业务闭环。
- 以LangGraph编排模型与工具循环、人工审批和MySQL检查点恢复；通过独立Streamable HTTP MCP提供业务工具，客户身份由服务器注入，模型只能提出候选申请。
- 将未发货退款、退货授权/收货后退款、补发、期限和风险校验落实到业务层；通过冻结审批快照、事务、唯一约束及条件更新保证受控执行和幂等。
- 建立128个条件明确的分区业务场景，分别保存结构化回归、Mock对照、有限真实模型、MySQL并发与故障恢复、Playwright浏览器验证，保留失败轨迹和可复算原始记录。
